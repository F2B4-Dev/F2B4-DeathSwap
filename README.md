# F2B4-DeathSwap

ระบบกิจกรรมสลับตำแหน่งผู้เล่นอัตโนมัติ (Death Swap) สำหรับเซิร์ฟเวอร์ Minecraft พัฒนาขึ้นสำหรับแพลตฟอร์ม Spigot และ Paper (รองรับ Minecraft เวอร์ชัน 1.20 ขึ้นไป)

---

## 1. ภาพรวมของระบบ (Overview)

F2B4-DeathSwap เป็นปลั๊กอินสำหรับจัดกิจกรรมเชิงเอาชีวิตรอด โดยระบบจะดำเนินการสุ่มจับคู่ผู้เล่นที่ออนไลน์อยู่ แล้วทำการสลับพิกัดตำแหน่ง (Teleport Swap) ซึ่งกันและกันเป็นระยะเวลาที่กำหนด ผู้เล่นจะต้องบริหารจัดการสถานการณ์เฉพาะหน้าเพื่อเอาชีวิตรอดจากตำแหน่งใหม่ที่ได้รับ โดยตัวปลั๊กอินมีระบบป้องกันผู้เล่นในพื้นที่ปลอดภัย ระบบกำหนดเวลาอัตโนมัติ และระบบแจ้งเตือนผ่าน Discord Webhook ในตัว

---

## 2. คุณสมบัติหลัก (Features)

1. **ระบบสลับตำแหน่งผู้เล่นแบบสุ่ม (Player Teleportation Swap)**
   - ดำเนินการสุ่มจับคู่และสลับพิกัดผู้เล่นทั้งหมดที่เข้าเกณฑ์พร้อมกัน
   - ปิดสถานะอมตะหลังการสลับตำแหน่งทันที (ตั้งค่า `NoDamageTicks` เป็น 0 และยกเลิกสถานะ `Invulnerable`) เพื่อให้เกิดความท้าทายในการเล่น
   - มีระบบตรวจสอบจำนวนผู้เล่นขั้นต่ำ โดยต้องมีผู้เล่นที่เข้าเกณฑ์อย่างน้อย 2 คนขึ้นไป ระบบจึงจะดำเนินการสลับตำแหน่ง

2. **ระบบนับถอยหลังและการแจ้งเตือนภายในเกม (Countdown & Alerts)**
   - ส่งสัญญาณเสียงและข้อความเตือนล่วงหน้าก่อนการสลับตำแหน่งที่ระยะเวลา 60 วินาที, 40 วินาที, 30 วินาที และนับถอยหลังทุกวินาทีในช่วง 20 วินาทีสุดท้าย
   - ข้อความแจ้งเตือนที่ระยะเวลา 1 นาที มีระบบลิงก์แบบ Interactive ให้ผู้เล่นสามารถคลิกเพื่อเปิดหน้าเว็บไซต์รายละเอียดกิจกรรมได้โดยตรง

3. **ระบบตารางเวลากิจกรรมอัตโนมัติ (Automated Schedule)**
   - ระบบจะเปิดการทำงานของกิจกรรมโดยอัตโนมัติตามวันและเวลาที่กำหนด:
     - วันพุธ และ วันอาทิตย์
     - รอบบ่าย: เวลา 15:00 น. - 16:00 น.
     - รอบค่ำ: เวลา 19:00 น. - 20:00 น.
   - ระหว่างช่วงเวลาดังกล่าว ระบบจะวนรอบการสลับตำแหน่งทุกๆ 5 นาที (300 วินาที)
   - มีระบบตรวจสอบเวลาคงเหลือภายในชั่วโมง หากเวลาที่เหลือไม่เพียงพอต่อรอบการสลับตำแหน่ง (น้อยกว่า 5 นาที) ระบบจะไม่เริ่มต้นรอบใหม่

4. **การบูรณาการร่วมกับ WorldGuard (Safe Region Protection)**
   - รองรับการเชื่อมต่อกับปลั๊กอิน WorldGuard โดยอัตโนมัติ
   - สามารถระบุชื่อ Region ที่เป็นเขตปลอดภัยในไฟล์การตั้งค่า เช่น บริเวณจุดเกิด (Spawn)
   - ผู้เล่นที่อยู่ในเขตปลอดภัย หรืออยู่ในโหมดสร้างสรรค์ (Creative Mode) และโหมดผู้ชม (Spectator Mode) จะได้รับการยกเว้นจากการถูกสลับตำแหน่ง

5. **ระบบแจ้งเตือนผ่าน Discord Webhook**
   - ส่งข้อความแจ้งเตือนในรูปแบบ Rich Embed ไปยัง Discord Channel เมื่อกิจกรรมเริ่มต้นและสิ้นสุดรอบ
   - สามารถกำหนดข้อความ หัวข้อ สี และไอคอนประจำตัว (Avatar URL) ได้ผ่านไฟล์การตั้งค่า

## 4. ข้อกำหนดของระบบ (Requirements)

- **Java Version:** 17 หรือ 21
- **Server Software:** Paper, Purpur หรือ Spigot (Minecraft เวอร์ชัน 1.20 ขึ้นไป)
- **Dependencies (ทางเลือก):**
  - **WorldGuard 7.x:** จำเป็นสำหรับการเปิดใช้งานระบบตรวจสอบเขตปลอดภัย (Safe Regions)
  - **WorldEdit:** ใช้งานร่วมกับ WorldGuard

---

## 5. การติดตั้ง (Installation)

1. ดาวน์โหลดไฟล์ `F2B4DeathSwap-1.0.jar`
2. นำไฟล์ไปวางในโฟลเดอร์ `plugins/` ของเซิร์ฟเวอร์
3. เริ่มต้นการทำงานของเซิร์ฟเวอร์ หรือสั่ง Reload ปลั๊กอิน
4. เข้าไปแก้ไขไฟล์ `plugins/F2B4_DeathSwap/config.yml` ตามที่ต้องการ แล้วรีสตาร์ทเซิร์ฟเวอร์

## 6. โครงสร้างไฟล์การตั้งค่า (Configuration)

โครงสร้างและค่าเริ่มต้นของไฟล์ `config.yml`:

```yaml
#notch is real

# F2B4 Death Swap Configuration
event-info-url: "https://google.com"

safe-regions:
  - "spawn"

  # ระบบแจ้งเตือน Discord Webhook
discord-webhook:
  enabled: false
  url: ""
  # ปรับแต่งข้อความ
  start-title: "กิจกรรม Death Swap เริ่มขึ้นแล้ว!"
  stop-title: "จบกิจกรรม Death Swap ประจำรอบนี้"
  avatar-url: "https://mc-heads.net/avatar/MHF_Skeleton"

# กิจกรรมจะจัดขึ้นโดยอัตโนมัติในทุกวัน พุธ และ อาทิตย์ ตามเวลาดังนี้
# รอบบ่าย 15:00 - 16:00
# รอบค่ำ 19:00 - 20:00
```

### คำอธิบายการตั้งค่าแต่ละส่วน

- `event-info-url`: URL หน้าเว็บไซต์ที่ต้องการให้ผู้เล่นเปิดเมื่อคลิกข้อความในเกม
- `safe-regions`: รายการชื่อ Region ใน WorldGuard ที่ต้องการยกเว้นไม่ให้ผู้เล่นในพื้นที่ดังกล่าวถูกสลับตำแหน่ง
- `discord-webhook.enabled`: กำหนดเป็น `true` เพื่อเปิดใช้งานระบบแจ้งเตือนผ่าน Discord
- `discord-webhook.url`: ที่อยู่ Webhook URL ของ Discord Channel ที่ต้องการส่งข้อความ
- `discord-webhook.start-title`: ข้อความหัวเรื่อง Embed เมื่อกิจกรรมเริ่มต้น
- `discord-webhook.stop-title`: ข้อความหัวเรื่อง Embed เมื่อกิจกรรมสิ้นสุด
- `discord-webhook.avatar-url`: ลิงก์รูปภาพสำหรับใช้เป็นภาพประจำตัวของผู้ส่งข้อความใน Discord
